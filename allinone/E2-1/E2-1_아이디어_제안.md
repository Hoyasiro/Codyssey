## 1. 약봄 — 어르신 다제약물 복약 안전 AI 코치 ⭐ 추천

**문제**
- 10종 이상 약을 만성 복용하는 사람은 2020년 약 93만 명 → 2025년 약 **144만 명**(+54%). 이 중 65세 이상이 **82%**.
- 85세 이상 10종 이상 복용자는 5년 새 **2.2배**.
- 건보공단이 약사 방문 상담(다제약물 관리사업)을 하지만 2025년 참여자는 1만 1,613명으로 대상자의 **0.8%**.
- 여러 병원에서 따로 처방받다 보니 같은 성분이 겹치거나, 함께 먹으면 안 되는 약이 섞임. 어르신은 그걸 알기 어려움.

**타겟 사용자**
- 주: 만성질환으로 여러 병원을 다니는 65세 이상 어르신
- 부: 부모 약을 챙기는 자녀(보호자), 방문 약사·보건소 간호사

**핵심 기능**
1. 약봉투·처방전 **사진 한 장 찍기** → OCR로 약 이름·용법 자동 등록
2. 등록된 약 전체를 대상으로 **병용금기·중복성분·노인주의 약** 자동 점검 → 위험하면 "약사·의사에게 확인하세요" 안내 + 보호자 알림
3. 정해진 시간에 **음성으로 복약 알림**, "드셨어요?" 대화로 복용 여부 기록
4. 진료 전에 "지금 먹는 약 목록 + 최근 불편 증상" **1장 요약지** 생성 → 의사에게 보여주기

**AI 기술**
| 기능 | 기술 | 이유 |
|---|---|---|
| 약봉투 인식 | OCR + 약품명 매칭(임베딩 검색) | 손글씨·약어가 섞여도 공식 약품명에 연결 |
| 위험 점검 | DUR 데이터 기반 규칙 + RAG(LLM이 근거 문서를 찾아 쉬운 말로 설명) | 판단은 공식 데이터로, 설명만 LLM → 지어내기 방지 |
| 복약 대화 | 음성인식(STT) + LLM + 음성합성(TTS) | 화면·글자 작은 앱이 어려운 어르신 고려 |

**차별점**: 기존 복약 알림 앱은 "알림"만, 공단 사업은 "사람 상담"만. 약봄은 **매일의 점검 + 쉬운 설명 + 보호자 연결**을 AI가 이어 줌. 진단·처방 변경은 하지 않고 "확인 권유"까지만 → 의료법 리스크가 낮음.

**데이터**: 공공데이터포털의 심평원 DUR 품목정보(병용금기·노인주의 등), 식약처 의약품 개요정보(e약은요) API.

**왜 우리 팀에 맞나**: 공공 API만으로 MVP 시연이 가능, 역할 분담이 깔끔함(OCR / RAG / 음성 / 화면·기획).

## 2. 골든루트 — 구급차 AI 중증도 분류 + 수용 병원 추천

**문제**
- 구급대가 현장에서 병원으로 출발하기까지 30분 넘게 걸린 이송: 전체의 **1.9%(2023) → 5.2%(2025)**. 전체 이송 건수는 13% 줄었는데 지연은 2.4배.
- 현장 체류 60분 이상: 3만 3,933건 → **7만 9,455건**.
- 구급대원이 처치하면서 병원에 일일이 전화로 수용 문의 → "응급실 뺑뺑이".

**타겟 사용자**: 119 구급대원, 광역 구급상황관리센터 상황요원

**핵심 기능**
1. 구급차 안 대화를 **실시간 텍스트로 변환** → 증상·활력징후 자동 추출
2. **Pre-KTAS 중증도 자동 추정** (근거 문장 표시, 최종 결정은 대원)
3. 병원별 **실시간 가용 병상 + 과거 수용/거절 패턴**으로 "받아줄 확률"까지 예측해 병원 순위 추천
4. 선택한 병원에 환자 요약 자동 전송

**AI 기술**: STT, LLM 기반 정보 추출·분류, 수용 확률 예측(LightGBM 등 분류 모델), 경로 시간 계산

**차별점 / 주의점**
- 정부도 2026년 호남권 시범사업(광역상황실이 병원 선정), 대구·경북 AI 이송체계 실증을 진행 중 → **문제가 진짜라는 증거**이면서 동시에 **경쟁이 있다는 뜻**.
- 우리 차별점은 "거리·병상"만이 아니라 **수용 거절 가능성까지 예측**하는 것.
- 실제 구급 데이터는 구하기 어려워 **합성 데이터로 시연**해야 함.

**데이터**: 국립중앙의료원 응급의료기관 실시간 가용병상 정보 API(공공데이터포털), 합성 구급 대화 시나리오.

## 3. 안부등 — 독거노인 생활 패턴 이상 감지 + AI 안부 대화

**문제**
- 65세 이상 1인가구 **245만 6천 가구**(2025 인구주택총조사), 1년 새 7.3% 증가, 일반가구의 10.9%로 역대 최대.
- 고독사·낙상 후 방치 등은 "평소와 다른 하루"를 빨리 알아채는 것이 핵심.

**타겟 사용자**: 혼자 사는 어르신, 생활지원사·지자체 담당자, 멀리 사는 자녀

**핵심 기능**
1. 전력·문 열림·움직임 센서(또는 스마트플러그) 데이터로 **그 사람만의 평소 패턴 학습**
2. 패턴이 깨지면(예: 아침 10시까지 움직임 없음) 바로 신고하지 않고 **AI 스피커가 먼저 말 걸기**
3. 대답이 없거나 대화에서 이상 징후(통증·어지럼 등)가 나오면 담당자·가족에게 단계별 알림
4. 주간 "생활 리듬 리포트"로 수면·활동 변화 추세 공유

**AI 기술**: 시계열 이상탐지(Isolation Forest, Autoencoder), 개인별 패턴 학습, LLM 음성 대화 + 위험 발화 분류

**차별점 / 주의점**: 정부의 응급안전안심서비스(센서 설치)가 이미 있음. 차별점은 **센서 알람 → AI 대화로 1차 확인**해 오경보를 줄이고 담당자 부담을 낮추는 것. 실제 센서 데이터가 없으면 공개 스마트홈 데이터셋 + 합성 데이터로 시연.

## 4. 세이프ICU — 중환자실 패혈증 조기 경보 (정규 과정 연계형)

**문제**: 패혈증은 치료 시작이 늦어질수록 사망 위험이 커짐. 중환자실 간호사·의사는 수많은 수치를 동시에 봐야 해서 초기 신호를 놓치기 쉬움.

**핵심 기능**: 활력징후·검사 수치 시계열로 **몇 시간 뒤 패혈증 위험 점수** 예측 → 왜 위험한지(어떤 수치가 영향을 줬는지) 설명 → 단계별 알림

**AI 기술**: LSTM/Transformer 시계열 예측, 확률 보정(Calibration), SHAP 근거 설명

**장점**: 코디세이 정규 과정 AI Healthcare **미션 1(ICU 패혈증 조기 경보 AI)과 같은 주제** → 이번 기획이 이후 학습으로 그대로 이어짐.
**단점**: 아이디어 자체가 새롭지 않아 아이디어톤에서 차별점을 내기 어려움. MIMIC 데이터는 교육 이수·승인 절차가 필요.
